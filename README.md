### Beach Runner
Este projeto de grupo tinha como objetivo utilizar 4 objetos com o tema da praia e criar um jogo com eles. 
A nossa ideia foi o Beach Runner, um jogo parecido com o Temple Run em que os objetos vêem em direção ao player e este tem de esquivar deles.
O jogo possui sistema de pontos para que o jogador possa ultrapassar a sua melhor pontuação.
O projeto foi desenvolvido com recurso ao editor de texto “Visual Studio Code” e a linguagem de programação utilizada foi o “Python”. 
A interface para realizar a renderização da cena e dos objetos foi o “OpenGL”. 
Esses objetos foram todos criados utilizando o programa “Blender”.
